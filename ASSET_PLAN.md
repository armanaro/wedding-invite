`#background-nasheed` is the existing audio element managed by `scripts/music.js`. Its expected path is `assets/audio/nasheed.mp3`; no visual-asset classification applies. The audio directory currently contains only `.gitkeep`, so this is an existing runtime slot rather than a present image file. It is intentionally not a recommendation to add or alter music.

## Audit guardrails

- No asset was created, replaced, moved, or removed for this plan.
- No scene, decoration category, or new visual concept was added. The descriptions only set replacement guidance for slots that already exist.
- The requested premium Indian-wedding/storybook direction is applied consistently: cream, muted emerald, antique gold, soft daylight, and restrained florals; the Nikah Hall and Surah scene retain their existing religious purpose without becoming separate visual worlds.
